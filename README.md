# Portfolio renewal package

이 패키지는 `BANSEOK-KANG1/Portfolio` 저장소의 홈(`index.html`)을 새 구조로 교체하기 위한 시안입니다.

## 포함 파일
- `index.html`
- `assets/css/renewal-home.css`
- `assets/js/renewal-home.js`

## 적용 방법
1. 기존 저장소 루트의 `index.html`을 백업합니다.
2. 이 패키지의 `index.html`을 저장소 루트에 덮어씁니다.
3. `assets/css/renewal-home.css`, `assets/js/renewal-home.js`를 동일 경로에 추가합니다.
4. 커밋 후 GitHub Pages에 배포합니다.

## 현재 연결되는 기존 페이지
- `pm.html`
- `intern.html`
- `branding.html`
- `data-insight.html`
- `reflection.html`
- `contact.html`

## 배포 전 체크 권장
- 이메일 주소 1개로 통일
- GitHub 링크 계정 1개로 통일
- Notion 링크 최신 URL 반영
- 실제 프로젝트 성과 수치가 있다면 카드 본문에 추가
